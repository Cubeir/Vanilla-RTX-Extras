# Vanilla-RTX-Extras
This repository holds extra Vanilla RTX Add-Ons and Extensions, such as Glowing Ores, Clear Water, Clear Glass, packages that extend support for Education Edition content (Chemistry RTX), Creative RTX, and more...

You can download the latest release packages from my [CurseForge](https://www.curseforge.com/members/cubeir) or [MCPEDL](https://mcpedl.com/user/cubeir) posts.

- **[Vanilla RTX Add-Ons:](https://mcpedl.com/vanilla-rtx-add-ons)** A series of smaller packs that can be modularly applied over Vanilla RTX to give certain blocks interesting non-vanilla properties.
- **[Chemistry RTX:](https://mcpedl.com/chemistry-rtx/)** Additional world-only resource packs to extend ray tracing support to content available under the Minecraft: Education Edition toggle.
- **[Creative RTX:](http://mcpedl.com/creative-rtx):** Replaces all Education Edition Element block textures with high definition and exotic materials for creative builds using ray tracing.
- **Ye Olde Resonator:** A special collection of Cubeir's personal edits to Vanilla RTX, released under the variant name "Vanilla RTX Before the Updates" to all Vanilla RTX supporters on Ko-Fi.
- **[Vanilla RTX Everwinter Extension](http://mcpedl.com/vanilla-rtx-everwinter):** Vanilla RTX's Festive extension that gets promoted during Christmas in the Vanilla RTX App.
